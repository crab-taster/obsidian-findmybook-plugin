# 书放哪了—图书录入｜书架整理｜阅读笔记（Obsidian 插件）

把「书放哪了」微信小程序里的**藏书、阅读计划、读书笔记**同步进 Obsidian vault，并以书架网格界面浏览。


## 安装和启用：

1. 打开obsidian的设置界面，找到第三方插件，打开社区插件市场，搜索“书放哪了”，安装插件。
2. 从“已安装插件”中，启用“书放哪了”。
3. 从左侧工具栏找到“书放哪了”

## 书籍同步：
1. 点左侧「📚」打开书架面板（或 `Cmd/Ctrl+P` 搜「打开书架」），或者右键「📚」。
2. 点「同步」按钮，会生成小程序码。
3. 二选一扫码：
   - **微信「扫一扫」**扫小程序码 
   - 从小程序的“更多”Tab页，进入“同步到obsidian”，点「扫码同步」。
3. 等待同步完成。

## 同步内容（写入 vault）

- 藏书：`书放哪了/<中图分类号> - <书名>.md`（分类号缺失时前缀为 `未分类`；分类号有多行时只取第一行）
- 计划 + 笔记：`书放哪了/笔记/<中图分类号> - <书名>.md`（该书无阅读数据则不生成）
- 书架总览：`书放哪了/书架总览.md`（书架 → 层 → 格）

增量策略：文件不存在则创建，内容变化才更新。

## 反向同步（把 Obsidian 的修改传回）

在 Obsidian 里改过的藏书信息字段（属性面板里的可改字段）可以回传小程序，**同样扫码**：

1. 命令面板执行「反向同步（把 Obsidian 的修改传回小程序）」（或设置页「回传修改」按钮）。
2. 插件与上次同步的**基线**对比，只挑出真正改过的字段/书。
3. 生成一次性二维码，用小程序扫码确认 → 后端把这些字段应用到你的书上（复用既有更新接口）。
4. 插件显示逐条回执（成功 / 失败原因），成功项刷新基线。

- 只上传**改动**字段，不动未改的书；元数据（`书名`/`作者`/… ）永远不会被回传（只读）。
- **护栏**：若检测到未回传的改动，正向同步会被阻止（否则服务器值会覆盖你的编辑）——先反向同步再正向同步。

## 书架视图

左侧栏「📚」图标打开侧边面板，卡片网格展示藏书（封面 / 书名 / 作者 / 位置 / 在架状态 / 阅读状态）。**点击卡片进入书籍详情页**。同步完成后会自动刷新。

筛选维度对齐小程序「找书」页，**全部在本地完成**

| 控件 | 说明 |
|---|---|
| 搜索 | 书名 / 作者 / 出版社 / ISBN / 位置 / 分类 / 标签 |
| 分类 | 选项从库里现有笔记汇总 |
| 书标签 | 同上（单选取一个标签；小程序是本地多选） |
| 在架状态 | 固定 5 项：在架 / 出借 / 赠送 / 卖出 / 遗失 |
| 阅读状态 | 固定 4 项：正在读 / 已搁置 / 已读完 / 还没读 |
| 排序 | 书名 / 作者 / 中图分类 / 购入日期（新→旧） |

## 设置项
- **同步目录**：藏书笔记写入的文件夹，默认 `书放哪了`。
- **立即同步**：一键发起一次二维码同步（下载）。
- **反向同步**：把笔记里改过的藏书信息回传小程序（上传）。
